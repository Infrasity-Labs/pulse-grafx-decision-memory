# Provenance

These two files are the instructions that were used to generate the first version of this repository with Claude Code. They are kept as a record of where the repo came from. They are not part of the demo and nothing reads them.

- [`okto-pulse-grafx-use-case-repo-plan.md`](okto-pulse-grafx-use-case-repo-plan.md): the plan for the repository.
- [`kickoff-prompt.md`](kickoff-prompt.md): the prompt that was pasted into Claude Code together with the plan. It speaks in the first person of that session and describes the repo as it was planned. It still calls the repo `pulse-grafx-decision-memory-demo` and still says to put the plan in an empty folder. The repo is now named `pulse-grafx-decision-memory`, and the demo has since changed. The README, the scoreboard and the findings describe what is in the repo now.
